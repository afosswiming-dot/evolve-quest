# EVOLVE Quest — Pixel UI Lab v0.2

Refinamento visual da v0.1, mantendo o laboratório completamente isolado do Web App oficial.

## O que mudou na v0.2

- correção de overflow horizontal no mobile;
- Mission Cards mais próximas da linguagem visual das referências;
- barras de progresso segmentadas;
- XP Bar refinada;
- HealerDialog mais compacto e integrado;
- pequenos ornamentos pixelados em CSS;
- modal de conclusão refinado;
- botões e estados com mais profundidade visual;
- sem aumentar a proporção de pixel art além do objetivo 70/30.

## Continua isolado

- sem Supabase;
- sem alterar outros módulos;
- sem screenshots usados como interface;
- sem mapa, combate, moedas, gemas ou inventário.

## Rota

Coloque a pasta `pixel-ui-lab` na raiz do repositório.
A rota permanece:

`/pixel-ui-lab/`
