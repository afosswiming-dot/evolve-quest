# EVOLVE Quest — Painel do Aventureiro v1.0.1 Integrado

Módulo integrado ao Supabase sem alterar o layout aprovado.

## Responsabilidade

- Consultar o estado atual da Jornada.
- Mostrar a próxima ação.
- Encaminhar para módulos especializados.
- Registrar apenas o último acesso ao painel.

## Rotas preparadas

- `/login/`
- `/missoes/`
- `/registro-missao/`
- `/manual/`
- `/jornada/`
- `/checkpoint/`
- `/registros/`
- `/perfil/`

## Importante

O painel não altera XP, Classe, Nível, progresso, pagamento, Missões ou Checkpoints. Quando o banco ainda não possui dados liberados pelo Healer, a interface mostra estados vazios em vez de dados demonstrativos.
